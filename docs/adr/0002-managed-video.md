# ADR-0002: الفيديو — خدمة مُدارة لا بناء ذاتي

- **الحالة:** مقبول
- **التاريخ:** 2026-06-09
- **السياق:** PRD §2، §3.2، §5.ب

## القرار

نعتمد **خدمة فيديو مُدارة** (Bunny Stream افتراضاً) للترميز والجودات
المتعددة (ABR) والتشغيل الموقّع وشبكة التوزيع (CDN). لا نبني خط فيديو ذاتياً
(FFmpeg + HLS + DRM) في الـ MVP.

## الأسباب

- البناء الذاتي عالي الكلفة تشغيلياً وهندسياً (ترميز، تخزين، CDN، DRM).
- الخدمة المُدارة تقدّم التشغيل الموقّع وABR وCDN جاهزة.

## التبعات

- حالة الفيديو تُتابَع عبر `webhook` من المزوّد (`processing` → `ready`)،
  مع **تحقق توقيع + idempotency** إلزامي.
- التشغيل عبر رابط/توكن موقّع قصير العمر، ومنع التنزيل المباشر.
- البناء الذاتي/DRM مؤجَّل صراحةً حتى يفرضه الحِمل (PRD §10).
