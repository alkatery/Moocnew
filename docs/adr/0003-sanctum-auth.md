# ADR-0003: المصادقة — Laravel Sanctum

- **الحالة:** مقبول
- **التاريخ:** 2026-06-09
- **السياق:** PRD §2، §3.3

## القرار

نعتمد **Laravel Sanctum** للمصادقة (الويب عبر Next.js، والجوال لاحقاً).

## الأسباب

- ملائم لـ SPA/Next.js وللتطبيق الجوال عبر التوكنات.
- أخفّ من Passport؛ لا حاجة لـ OAuth لطرف ثالث في الـ MVP.

## التبعات

- المستخدمون يستخدمون `HasApiTokens`.
- إن لزم OAuth لطرف ثالث لاحقاً، يُعاد النظر عبر ADR جديد (Passport).
