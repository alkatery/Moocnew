# ADR-0001: تعدد المستأجرين — مفردة المستأجر (Single-tenant)

- **الحالة:** مقبول
- **التاريخ:** 2026-06-09
- **السياق:** PRD §3.1

## القرار

نبني المنصة **مفردة المستأجر (Single-tenant)** في الـ MVP: قاعدة بيانات
واحدة بلا عمود `tenant_id` على الجداول.

## الأسباب

- الـ PRD يصف منصة واحدة لجهة واحدة، لا منصة بيضاء (White-label).
- إضافة تعدد المستأجرين قبل وجود طلب فعلي هندسة زائدة تعقّد كل migration
  واستعلام.

## التبعات

- لا أعمدة/نطاقات (scopes) خاصة بالمستأجر في المرحلة الحالية.
- التحوّل لاحقاً إلى تعدد المستأجرين مكلف؛ يتطلب ADR جديداً وترحيلاً شاملاً.
  عزل السياقات المحدودة يخفّف هذه الكلفة جزئياً.
