# عقد الدفعة D4 — البحث في نصّ الدرس + ضوابط المشغّل

> **الحالة:** نهائي للتنفيذ — يسلّمه `frontend-dev` حرفياً (`backend-dev` لا عمل عليه — انظر §0).
> **المرجع:** `docs/implementation-plan.md §5 D4` · `docs/PRD-MOOC-Platform-v2.md §5.ج (الوصول/المشغّل)` · `docs/architecture/CONTEXTS.md` (Enrollment + Catalog) · المصفوفة: «المشغّل المتسلسل» / «مشغّل الفيديو» / «النصوص التفاعلية» (الثلاثة `جزئي`، `frontend-dev`).

## 1. عقد الواجهة الوظيفي (لا API جديد)

> **لا مسارات جديدة، لا تغيير في أي استجابة قائمة.** المسارات المستهلَكة (كلها قائمة):
> ```
> GET  /api/v1/lessons/{lesson}/content                 → { data: { transcript, ... } }      (النصّ)
> GET  /api/v1/lessons/{lesson}/playback                → { playback: { kind, url } }         (المصدر)
> GET  /api/v1/catalog/courses/{course}/progress        → { data: { lessons: [{lesson_id, video_position, completed}] } }  (الاستئناف/الإكمال)
> POST /api/v1/lessons/{lesson}/progress { video_position }   → حفظ الموضع                    (قائم — يُستدعى عند المغادرة/التقدّم)
> ```

### 1.أ — البحث في نصّ الدرس (لوحة النصّ — بلا قفز زمني)

- **المكان:** يحلّ محلّ لوحة النصّ الحالية في `learn/[slug]/page.tsx:254-260` (حالياً `<details>` تعرض `content.transcript` خام).
- **الظهور:** فقط عند `active?.type === 'video' && content?.transcript` (كما اليوم).
- **المكوّنات:**
  - حقل بحث نصّي (`<input>` معنون) فوق النصّ.
  - عند كتابة استعلام غير فارغ: **تظليل** كل التطابقات (غير حسّاس لحالة الأحرف) داخل نصّ التفريغ.
  - **عدّاد نتائج:** «النتيجة س من ص» (مثال: «٢ من ٧») — أو «لا نتائج» عند الصفر.
  - **تنقّل النتائج:** زرّا «النتيجة السابقة / التالية» يحرّكان «النتيجة النشطة» (تمييز بصري أبرز + `scrollIntoView` داخل اللوحة فقط) دوريّاً.
- **مطابقة آمنة (إلزامي):** المطابقة على **نصّ عادي** (substring غير حسّاس للحالة)، **لا regex من إدخال المستخدم** (تجنّب أخطاء/حقن نمط). تنظيف/تهريب أي قيمة قبل بنائها في تعبير، أو استخدم `indexOf` تكراريّاً. التظليل عبر تقطيع النصّ وتغليف المطابقات بعنصر `<mark>` — **لا `dangerouslySetInnerHTML` بنصّ غير مهرَّب**.
- **العربية:** المطابقة تعمل على نصّ عربي RTL؛ التطبيع (تجاهل التشكيل/همزات متغايرة) **خارج v1** (مطابقة حرفية تكفي معيار القبول؛ يُحسَّن لاحقاً عند الطلب).
- **حدّ الأداء:** نصوص التفريغ قصيرة-متوسطة؛ التظليل تزامني مقبول. لا حاجة لـ debounce معقّد (debounce خفيف ~150ms اختياري لتجربة أنعم).
- **لا قفز زمني:** لا رابط/سلوك ينقل `currentTime` من نتيجة بحث (لا طوابع). إن رغب المنتج بتلميح: نصّ توضيحي صغير «البحث يظلّل داخل النصّ؛ الانتقال الزمني يتطلّب تفريغاً موقوتاً (قيد التطوير)» — **اختياري، لا يَعِد بميزة غير موجودة**.

### 1.ب — ضوابط مشغّل الفيديو (`signed_url` / `<video>` فقط)

تُعرض **أسفل/فوق** عنصر `<video>` (السطر 146) وتعمل عبر `videoRef`:

- **السرعة (`playbackRate`):** أزرار/قائمة `0.75× · 1× · 1.25× · 1.5× · 2×`. النقر يضبط `videoRef.current.playbackRate`. الزرّ النشط يعكس السرعة الحالية (`aria-pressed`). الافتراضي `1×`.
- **الاستئناف الظاهر:** انظر §1.ج (سلوك متكامل).
- **لا أزرار جودة/تنزيل:** (قرار §0 — المصدر واحد وموقّت). لا تُضِفها للـ `<video>`.
- **ضوابط المتصفّح الأصيلة تبقى:** `controls` على `<video>` (تشغيل/إيقاف/شريط زمن/صوت/ملء الشاشة) — لا نعيد بناءها.

> **`embed` (iframe):** **لا ضوابط مخصّصة** — كلّ ذلك من مشغّل المزوّد. يظهر لها فقط شريط «سابق/تالٍ» (§1.د) خارج iframe.

### 1.ج — الاستئناف من آخر موضع (Resume)

- **القراءة:** عند فتح المشغّل (أو في `useEffect` للصفحة) اجلب `GET /catalog/courses/{slug}/progress` مرّةً وابنِ خريطة `lessonId → { video_position, completed }`. (يجوز جلبها مع تحميل الدورة لتفعيل أيضاً علامات «مكتمل» في القائمة الجانبية — تحسين اختياري متّسق.)
- **عند فتح درس فيديو `signed_url` له `video_position > 0`:**
  - **لا تقفز تلقائياً فوراً وبصمت.** أظهر **شريط إشعار ظاهر** فوق/أسفل المشغّل: «المتابعة من **د:ث**» + زرّان:
    - **«استئناف»** → يضبط `videoRef.current.currentTime = video_position` ثم (اختياري) `play()`.
    - **«من البداية»** → يبدأ من `0` (يُخفي الإشعار دون تغيير `currentTime`).
  - تنسيق **د:ث** عربي (مثال `12:34` أو «الدقيقة ١٢:٣٤») — معنون بوضوح.
  - بديل مقبول (إن فُضّل): الضبط التلقائي على الموضع المحفوظ **مع** إشعار «استأنفنا من د:ث — [العودة للبداية]». المهم: **الموضع واضح للمستخدم وقابل للإلغاء بزرّ «من البداية»** (معيار قبول).
- **الحفظ (أثناء التشغيل):** عبر `POST /lessons/{lesson}/progress { video_position: Math.floor(videoRef.currentTime) }`:
  - على حدث `pause` و/أو `beforeunload`/مغادرة الدرس، و(اختياري) كل ~15–30ث أثناء التشغيل (throttle). **لا إرسال لكل `timeupdate`** (إغراق الشبكة).
  - الفشل صامت لا يكسر التشغيل (`.catch(() => {})` كنمط `complete` الحالي).
- **حدود:** الاستئناف **لـ `signed_url` فقط** (لا نتحكّم بزمن iframe). لا تُظهر إشعار استئناف لدروس `embed`.

### 1.د — أزرار «سابق / تالٍ» (المشغّل المتسلسل)

- **التسلسل:** تسطيح `course.sections` (بترتيب `position`) ثم `lessons` داخل كلٍّ (بترتيب `position`) → مصفوفة دروس خطّية. أوجد فهرس `active` فيها.
- **المكان:** شريط تنقّل قرب رأس/أسفل منطقة المشغّل (يظهر لكل أنواع الدروس، لا الفيديو فقط).
- **السلوك:**
  - **«الدرس السابق»** → يفتح الدرس عند `index-1` (يستدعي `open()` القائم).
  - **«الدرس التالي»** → يفتح الدرس عند `index+1`.
  - **عند الحدود:** زرّ «السابق» **معطَّل** (`disabled` + `aria-disabled`) في أول درس؛ زرّ «التالي» معطَّل في آخر درس.
  - **حفظ التقدّم عند التنقّل:** قبل مغادرة درس فيديو `signed_url` جارٍ، أرسل `video_position` الحالي (نفس مسار §1.ج) — لا يضيع موضع المتعلّم عند الضغط «التالي/السابق».
- **اختياري (تحسين، لا إلزام):** إظهار عنوان الدرس التالي/السابق بجوار الزرّ.

### 1.هـ — ما هو **ليس** جزءاً من D4 (توضيح حدود)

- القفز الزمني من **الملاحظات** (`lesson_notes.at_seconds`) موجود مسبقاً في `LessonInteraction` (السطر 247-251، عبر `seekTo`) — **لا نلمسه**؛ هو ليس «نصّ التفريغ».
- نقاط التحقّق داخل الفيديو (`checkpoints`) موجودة — خارج نطاق D4.

## 2. حدود الموديول (Bounded Contexts)

- **دفعة أمامية بحتة — صفر تغيير خلفي.** لا تُمسّ طبقات Domain/Application/Infrastructure.
- **Enrollment (يملك التشغيل والتقدّم):** يُقرأ فقط عبر مساراته القائمة (`playback`, `progress`, `course.progress`). لا تعديل في `PlaybackController`/`ProgressService`/`PlaybackTarget`.
- **Catalog (يملك الدرس/النصّ/الترتيب):** يُقرأ فقط عبر `/lessons/{lesson}/content` و`sections[].position`/`lessons[].position`. لا تعديل في `Lesson`/`LessonContentController`.
- **لا منطق مجال في الواجهة:** البحث/التظليل/التسطيح/تنسيق الزمن منطق عرض محض (presentation) — مكان طبيعي للأمامية، لا يكرّر قاعدة عمل خلفية.
- **شرط عدم التوسّع:** إن طُلب لاحقاً «قفز زمني حقيقي» فهو **تغيير مخطّط** (حقل cues/VTT على `lessons` + هجرة + تعديل `transcript`) — **عقد منفصل**، لا يُهرَّب داخل D4.

## 5. معايير القبول (قابلة للاختبار — Vitest، qa-tester)

> دفعة أمامية → الاختبارات أمامية (لا Feature خلفي جديد؛ المسارات المستهلَكة مغطّاة بدفعات سابقة). qa-tester قد يضيف تأكيد تكامل خفيف أن الواجهة تستدعي `progress`/`content` الصحيحة (mock).

1. **البحث يظلّل ويعدّ:** كتابة استعلام يطابق ٣ مواضع في التفريغ → تظهر ٣ عناصر `<mark>` والعدّاد يعرض «١ من ٣» (أو ما يعادله)؛ استعلام بلا تطابق → «لا نتائج» ولا `<mark>`.
2. **تنقّل النتائج:** «التالية» يُحرّك النتيجة النشطة دورياً ويحدّث العدّاد؛ معطَّل عند نتيجة وحيدة.
3. **لا قفز زمني من البحث:** لا عنصر بحث يغيّر `video.currentTime` (تأكيد سلبي — يثبّت قرار v1).
4. **السرعة تغيّر `playbackRate`:** نقر «١.٥×» يجعل `videoRef.playbackRate === 1.5` و`aria-pressed` ينتقل للزرّ النشط (لدرس `signed_url`).
5. **الاستئناف:** درس فيديو `signed_url` بـ `video_position = 120` (من mock `progress`) → يظهر إشعار «المتابعة من ٢:٠٠»؛ «استئناف» يضبط `currentTime ≈ 120`؛ «من البداية» يُبقي `currentTime = 0` ويُخفي الإشعار.
6. **لا استئناف للـ embed:** درس `embed` لا يُظهر إشعار استئناف ولا أزرار سرعة (الضوابط للمزوّد).
7. **لا زرّ تنزيل/جودة:** لا عنصر «تنزيل» ولا «جودة» في مشغّل `signed_url` (تأكيد سلبي — يثبّت قرار المصدر الموقّت/الواحد).
8. **سابق/تالٍ عند الحدود:** في **أول** درس بالتسلسل المسطّح → «السابق» `disabled`؛ في **آخر** درس → «التالي» `disabled`؛ في الوسط كلاهما فعّال ويفتح الدرس الصحيح بترتيب القسم→الدرس.
9. **حفظ عند التنقّل:** الضغط «التالي» من درس فيديو `signed_url` جارٍ يستدعي `POST /lessons/{id}/progress` بـ `video_position` الحالي (mock — تأكيد الاستدعاء).
10. **حالات اللوحة:** نصّ غير موجود (`transcript === null`) → لا تظهر لوحة البحث أصلاً؛ نصّ موجود → تظهر مع الحقل والعدّاد.

## 7. ما هو خارج النطاق (لا هندسة زائدة — يُراجَع فقط بقرار صريح)

- **القفز الزمني من نصّ التفريغ:** يتطلّب تفريغاً موقوتاً (VTT/cues) — تغيير مخطّط + هجرة، **عقد منفصل**. v1 = بحث/تظليل فقط.
- **جودة متعدّدة (resolution switcher):** المصدر مُدار واحد؛ لا قائمة مصادر في الاستجابة. لا نضيفها ولا نَعِد بها.
- **تنزيل الفيديو:** يخالف نموذج التشغيل الموقّت الموقّع — لا زرّ تنزيل لـ `signed_url`/`embed`.
- **تطبيع النصّ العربي للبحث** (تشكيل/همزات/ألف مقصورة): مطابقة حرفية تكفي v1؛ تحسين لاحق عند الطلب.
- **ضوابط مخصّصة فوق iframe (embed):** غير ممكنة تقنياً عبر الحدود؛ نعتمد مشغّل المزوّد.
- **تظليل عبر دروس متعدّدة / بحث في كامل الدورة:** البحث ضمن نصّ الدرس النشط فقط (مطابق هدف الدفعة؛ «البحث داخل/عبر المقررات» بند مستقلّ في المصفوفة).
- **شريط تقدّم/Scrubbing مخصّص:** نعتمد `controls` الأصيل لـ `<video>` — لا نعيد بناء عناصر التحكّم القياسية.
