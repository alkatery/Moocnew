# بنية السياقات المحدودة (Bounded Contexts)

المنصة **Modular Monolith**: نواة واحدة منظَّمة في سياقات محدودة داخل
`app/Contexts/`. كل سياق مفصول إلى ثلاث طبقات بحدود صارمة:

| الطبقة | المسؤولية | يعتمد على |
|---|---|---|
| **Domain** | كيانات، كائنات قيمة، تعدادات، عقود (interfaces) — منطق أعمال نقي بلا أي اعتماد على الإطار. | لا شيء |
| **Application** | خدمات تطبيقية، أوامر/استعلامات — تنسّق منطق الـ Domain. | Domain فقط |
| **Infrastructure** | تطبيقات Eloquent للعقود، مزوّدو الخدمة (Providers)، تكاملات خارجية (S3، فيديو، دفع)، migrations. | Domain + Application |

القاعدة الذهبية: **Domain لا يعرف Infrastructure**. الربط يتم عبر الحاوية
(Container) في `…ServiceProvider`، حيث يُربط عقد الـ Domain بتطبيق
الـ Infrastructure.

## السياقات

| السياق | الغرض | الحالة |
|---|---|---|
| `Platform` | الإعدادات (`settings`) ورايات الميزات (`FeatureFlags`). | ✅ مُنجَز |
| `Identity` | المستخدمون، الأدوار، الملف الشخصي، موافقات PDPL، سجل التدقيق. | ✅ مُنجَز |
| `Catalog` | التصنيفات، الدورات، الأقسام، الدروس، البحث (Scout)، مزوّد الفيديو. | ✅ مُنجَز |
| `Enrollment` | `EnrollmentService`، آلة الحالة، التقدم، التشغيل الموقّع، webhook الفيديو. | ✅ مُنجَز |
| `Assessment` | الاختبارات، بنك الأسئلة، التصحيح الآلي، الواجبات. | ✅ مُنجَز |
| `Certification` | الشهادات والتحقق العام (QR). | ✅ مُنجَز |
| `Notification` | القنوات (بريد/SMS/داخل التطبيق) ومركز التفضيلات. | ✅ مُنجَز |
| `Analytics` | الإحصاء المُجمَّع وعدّاد التواجد (Redis). | ✅ مُنجَز |
| `Commerce` | الطلبات، الدفع، الفواتير، دفتر الأستاذ، السحوبات. | 🔒 هيكل خلف الراية — المرحلة 2 |

## عزل التجارة خلف الراية

سياق `Commerce` هو الوحيد المحكوم براية `payments.enabled` (انظر
[ADR-0004](adr/0004-commerce-behind-feature-flag.md)):

- **مساراته محجوبة** خلف وسيط `payments.enabled`: تُعيد `404` حين تكون
  الراية مُعطَّلة (محايد لـ route cache ويسمح بالتبديل اللحظي دون إعادة نشر).
- الالتحاق **لا يعتمد** على الطلبات؛ `enrollments.order_id` اختياري (`nullable`)
  وبلا مفتاح أجنبي حتى المرحلة 2.
- عند التعطيل: المنصة تعمل بالكامل مجاناً، وتُخفى الأسعار والسلة والفواتير.

مصدر الحقيقة للراية هو جدول `settings` (مُكاش في Redis)، ويُقرأ عبر
`App\Contexts\Platform\Application\FeatureFlags`.

## التسجيل

كل سياق يسجّل `…ServiceProvider` في `bootstrap/providers.php`. مسارات API
تُجمَّع تحت `/api/v1` (انظر `bootstrap/app.php` و`routes/api.php`).
