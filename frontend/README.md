# واجهة منصة MOOC (Next.js)

واجهة الويب للمنصة — **Next.js (App Router) + TypeScript**، بتصميم **RTL** وخط
**Tajawal** و**i18n** (العربية افتراضياً، الإنجليزية احتياطية). تتصل بالواجهة
الخلفية عبر `/api/v1` بمصادقة توكن Sanctum.

## التشغيل
```bash
cp .env.example .env.local   # اضبط NEXT_PUBLIC_API_BASE على عنوان الـ API
npm install
npm run dev                  # تطوير
npm run build                # بناء إنتاجي
npm test                     # اختبارات Vitest
npm run typecheck            # فحص الأنواع
```

## الشاشات المنجزة (الشريحة المجانية)
- الدخول والتسجيل (مع موافقة PDPL) عبر توكن Sanctum.
- الكتالوج: قائمة الدورات + بحث.
- تفاصيل الدورة + الالتحاق.
- «تعلّمي»: دوراتي مع نسبة الإنجاز.
- مشغّل الدورة: قائمة الدروس + تشغيل موقّع (فيديو/تضمين) + إكمال الدرس.

## البنية
- `src/lib/api.ts` — عميل API مكتوب الأنواع (توكن Sanctum في localStorage).
- `src/lib/auth.tsx` — سياق المصادقة (دخول/تسجيل/خروج/me).
- `src/i18n/dictionary.ts` — قاموس الترجمة (ar/en).
- `src/app/*` — صفحات App Router.

> شاشات لاحقة (متابعة): لوحات المدرّس/الإدارة، السلة والدفع (المرحلة 2)،
> ساحات النقاش، التقويم، مركز الإشعارات.
